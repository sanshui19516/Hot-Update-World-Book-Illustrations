<llm_image_insertion_rules>
图片插入执行规范

核心原则:
  唯一来源: <sfw_image>和<nsfw_image>
  格式统一: 严格遵循标签格式
  禁止创造: 不得使用列表外的任何路径

标签格式:
  SFW标签: <SFW_IMG>${动作描述}/${数字}.jpg</SFW_IMG>
  NSFW标签: <NSFW_IMG>${动作描述}/${数字}.jpg</NSFW_IMG>

路径要求:
  - 完整路径: 动作描述/数字.jpg
  - 数字选择: 在指定范围内随机
  - 路径分隔: 使用"/"，禁止空格

插入策略:
  - 数量控制: 每次回复插入1-2张匹配当前剧情的插图
  - 重复限制: 同一描述不重复使用
  - 场景不符时跳过

时机判定:
  - 内容匹配: 插图必须与当前段落的文字内容完全对应
  - 场景不符: 如果当前场景没有匹配的插图，直接跳过
  - 位置要求: 插图必须紧跟相关段落之后

场景规则:

  【SFW 插图】日常、情感、生活场景使用：

    外出场景：
      - 外出在公园坐着 → 公园长椅、草地、阳光下的户外时光，适合描写散步、休息、约会
      - 外出逛街 → 商场、街道、拎着购物袋，适合描写一起出门、日常约会
      - 电影院 → 黑暗的影厅、银幕的光映在脸上，适合描写看电影、约会、暧昧氛围

    居家日常：
      - 她做饭 → 厨房里穿着日常衣服忙碌，适合描写家常、温暖、同居生活
      - 她只穿着围裙做饭 → 围裙下没穿别的衣服，适合描写同居、亲密、日常中的挑逗
      - 她在沙发上睡觉 → 蜷在沙发上睡着了，适合描写放松、毫无防备的姿态
      - 她在阳台 → 站在阳台栏杆边，风吹动头发，适合描写黄昏、独处、放空
      - 她坐在床上 → 坐在床边低头或看书，适合描写早晨、夜晚、私密空间
      - 她坐在沙发上 → 窝在沙发里看电视或发呆，适合描写日常、放松
      - 她弯腰 → 弯下腰捡东西或做事，适合描写日常动作、不经意间的美
      - 她趴在沙发上 → 趴在沙发上看手机或休息，适合描写慵懒、家居姿态
      - 她跨坐在我身上 → 面对面跨坐在腿上，适合描写亲密互动、调情
      - 她站在窗边 → 站在窗前看窗外或转身看来，适合描写晨光、心事、等待
      - 她洗漱 → 在洗手台前刷牙或洗脸，适合描写早晨、刚睡醒、同居日常
      - 打电话 → 拿着手机贴在耳边说话，适合描写通话、等待、心事
      - 她挽着我的手 → 手臂挽着手臂并肩走，适合描写外出、亲密、撒娇
      - 她吃醋看着我 → 眼神带着醋意盯着你看，适合描写吃醋、小情绪
      - 她喝酒 → 端着酒杯小口抿着，适合描写微醺、放松、暧昧氛围
      - 我放学回家，她站在楼道 → 放学回来看到她在楼道里等着，适合描写等待、惊喜、日常相遇

  【NSFW 插图】亲密、性爱场景使用（剧情推进到适当阶段时）：
      - 内射 → 在体内射精的性爱行为，适合描写亲密高峰、无保护
      - 口交 → 用嘴含住性器，适合描写前戏、亲密
      - 后入 → 从后方进入的体位，适合描写激烈性爱
      - 站立式后入 → 站立姿态下的后入体位，适合描写随性、激情
      - 床上口交 → 在床上进行口交，适合描写床上前戏、亲密
      - 床上她的裸体 → 她赤裸的身体躺在床上，适合描写性爱后、裸体相对
      - 她衣服滑落 → 衣服从肩头滑落，露出身体，适合描写脱衣、前戏、挑逗

验证要点:
  - SFW场景只使用SFW标签，NSFW场景只使用NSFW标签
  - 数字在指定范围内
  - 格式规范，无空格

正确示例:
  <SFW_IMG>她坐在沙发上/3.jpg</SFW_IMG>
  <SFW_IMG>她只穿着围裙做饭/5.jpg</SFW_IMG>
  <NSFW_IMG>后入/7.jpg</NSFW_IMG>

错误示例:
  <SFW_IMG>她坐在沙发上/99.jpg</SFW_IMG>  <!-- 超出范围 -->
  <SFW_IMG> 她坐在沙发上 / 3.jpg</SFW_IMG>  <!-- 含有空格 -->
</llm_image_insertion_rules>
